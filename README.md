# FastAPI Continuous Integration (CI/CD) Practice

Практический проект, демонстрирующий навыки автоматизированного тестирования асинхронного FastAPI-приложения и настройки пайплайнов непрерывной интеграции (CI/CD).

## Назначение проекта
Проект создан для отработки процессов автоматического контроля качества кода:
- Написание модульных тестов с использованием фреймворка **Pytest**.
- Настройка линтеров (**Flake8**) для проверки соответствия кода стандарту PEP 8.
- Архитектурное построение автоматических проверок (пайплайнов) при каждом коммите.

## Настройка и локальный запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   cd fastapi-ci-practice
   ```

2. Настройте виртуальное окружение и установите зависимости:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```

3. Запустите автоматические тесты:
   ```bash
   pytest
   ```

## CI/CD Инфраструктура
В репозитории сконфигурированы сценарии для автоматического тестирования:
- `.github/workflows/` — пайплайн для GitHub Actions.
- `.gitlab-ci.yml` — конфигурация для сред GitLab CI.

## Стек технологий
Python, FastAPI, Pytest, Flake8, GitHub Actions, GitLab CI.
